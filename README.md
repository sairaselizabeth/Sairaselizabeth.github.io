# Saira S Elizabeth — Cybersecurity Portfolio

A recruiter-focused portfolio built with **Python + Flask**.

## Positioning
- B.E. Computer Science & Engineering
- 1.5+ years professional software development experience
- Cyber Security Analyst training
- Focus: VAPT, Application Security, Web/Mobile Security, Python security automation

## Run locally

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`.

## Edit your details
Most recruiter-facing content is at the top of `app.py` in:
- `PROFILE`
- `SKILLS`
- `PROJECTS`
- `EXPERIENCE`

Only add certifications, tools, employers, dates or claims that you can substantiate.
